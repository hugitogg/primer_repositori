# Fitxa tècnica: Instal·lació d'Ubuntu Server

## Objectiu

Instal·lar Ubuntu Server en una màquina virtual de VirtualBox i deixar el sistema preparat per realitzar pràctiques d'administració de sistemes.

## Materials

* Ordinador
* VirtualBox
* ISO d'Ubuntu Server
* Connexió a Internet
* Visual Studio Code
* Repositori Git
